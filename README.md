# サウナフォーカス

スマホ断ち × サウナ × 自律神経整えをテーマにした習慣改善アプリです。

## Web版

https://ho111so627rora-star.github.io/sauna-focus-app/

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy-web.yml`）が Web 版をビルドして GitHub Pages に公開します。

## アプリのコンセプト

このアプリは、ユーザーがスマホを触らない・集中する時間を、仮想のサウナ体験（サウナ室→水風呂→外気浴）に重ねることで、整う感覚を味わえる構成になっています。

### セッションの流れ

1. **サウナ室（25分）**: 集中タイマーとして使用
   - 残り5分で「ロウリュ」ボタンが表示
   - 応援演出と音で最後の踏ん張りを促す

2. **水風呂（5分）**: 呼吸音＋青い背景
   - 冷たい水で心身をリフレッシュ

3. **外気浴（5分）**: 風や虫の音＋日記入力画面
   - 自然の風を感じながら心を落ち着かせる
   - セッションの振り返りを記録

## 機能

- ✅ サウナ体験に基づいた集中タイマー
- ✅ ロウリュ演出機能
- ✅ 各フェーズに応じた環境音（準備中）
- ✅ 日記機能
- ✅ セッション履歴の保存・表示
- ✅ 美しいアニメーション効果
- ✅ ローカルストレージでのデータ保存

## セットアップ

### 必要な環境

- Flutter SDK 3.8.1以上
- Dart SDK
- iOS Simulator または Android Emulator

### インストール手順

1. リポジトリをクローン
```bash
git clone <repository-url>
cd sauna-focus-app
```

2. 依存関係をインストール
```bash
flutter pub get
```

3. アプリを実行
```bash
flutter run
```

## 必要な音声ファイル

以下の音声ファイルを `assets/audio/` フォルダに配置してください：

- `sauna_ambient.mp3` - サウナ室の環境音
- `cold_bath_ambient.mp3` - 水風呂の環境音
- `air_bath_ambient.mp3` - 外気浴の環境音
- `lowryu_sound.mp3` - ロウリュ音
- `session_complete.mp3` - セッション完了音

## 技術スタック

- **フレームワーク**: Flutter
- **状態管理**: Provider
- **ローカルストレージ**: SharedPreferences
- **音声再生**: AudioPlayers
- **アニメーション**: Flutter Animation

## 画面構成

1. **ホーム画面**: アプリのメイン画面、セッション開始ボタン
2. **サウナ室画面**: 集中タイマー、呼吸アニメーション
3. **水風呂画面**: 水の波紋エフェクト、リフレッシュ時間
4. **外気浴画面**: 日記入力、風のアニメーション
5. **履歴画面**: 過去のセッション記録一覧
6. **完了画面**: セッション完了の祝賀画面
